# USTAAD AI Android prototype

Use GitHub Actions → Build Android APK → Run workflow to compile a debug APK. The web app is copied into www/index.html for Capacitor. Internet is required for Quran text and audio. Microphone records and replays only: **no automated correction of Hafs or tajwid**. Browser recording requires microphone permission and a secure context. APK compilation is not guaranteed until the workflow completes successfully.
